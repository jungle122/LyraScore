# Lyra 曲谱库

> 使用微信云开发跨设备保存并整理曲谱。

一款微信小程序，用于保存、搜索和分组整理吉他谱。支持自制文字谱、图片/PDF 导入、纸质谱归档、歌单及多维筛选。

> ℹ️ **架构演进**：项目曾从微信云开发迁移为纯本地存储。本分支重新启用 **微信云开发**，曲谱元数据写入云数据库 `songs` 集合，图片/PDF 写入云存储；`utils/localStore.js` 暂时保留，供后续迁移和回退使用。

## ✨ 核心功能

### 1. **曲谱管理**
- **图片/PDF 导入**：上传曲谱截图、照片或聊天文件
- **纸质谱归档**：记录书名、页码，并可保存备份图片
- **旧数据兼容**：历史文字谱支持查看和编辑

### 2. **搜索、筛选与歌单**
- **搜索功能**：按歌名、歌手名搜索，排除回收站
- **组合筛选**：按乐器、演奏方式和曲谱类型筛选
- **排序方式**：最新存入、最早存入、名称排序；编辑不改变存入时间
- **歌单整理**：一首曲谱可加入多个歌单，支持新建、改名、删除和批量管理

### 3. **曲谱管理**
- 原“正在练”和“已练完”合并为统一曲谱库
- 图片/PDF 曲谱与纸质谱支持新增和编辑
- 支持添加和编辑自制文字谱，保留和弦、歌词及调性等信息
- 回收站支持恢复、手动清空和可重试的附件清理

### 4. **辅助工具**
- 🎺 **调音器**：实时音频识别
- ⏰ **节拍器**：可调节速度和拍号
- 🔒 **屏幕常亮**：读谱时防止屏幕自动熄灭

### 5. **阅读器**
- 📖 **文本展示**：自制谱内容清晰展示
- 📷 **图片浏览**：导入谱的图片查看
- ✏️ **快速编辑**：无需返回，一键进入编辑

### 6. **外观**
- 显示模式：跟随系统（默认）、白天、黑夜
- 配色：经典粉色、中性黑灰；设置保存在当前设备
- 页面、导航栏、底栏及上下回弹区域同步切换

## 📊 数据结构（云数据库）

每首曲谱对应云数据库 `songs` 集合中的一条记录；图片/PDF 上传至云存储，记录中保存对应的 `cloud://` 文件 ID。

```javascript
{
  _id: String,                // 云数据库文档 ID
  id: Number,                 // 时间戳（页面跳转用）
  type: String,               // 'blank' | 'paper' | 'image'
  status: String,             // 新数据为 'active'；兼容旧状态；删除为 'deleted'
  title: String,              // 歌曲名
  artist: String,             // 歌手名
  instrument: String,         // '吉他' | '尤克里里'
  style: String,              // '弹唱' | '指弹'
  
  // 自制文字谱字段
  key: String,                // 选调
  originalKey: String,        // 原调
  capo: Number,               // Capo位置
  timeSignature: String,      // 拍号
  bpm: Number,                // 速度
  tuning: String,             // 调音方式
  content: String,            // 和弦和歌词内容
  comment: String,            // 备注
  
  // 纸质谱字段
  location: String,           // 位置（书名、页码等）
  
  // 图片谱字段
  imagePaths: Array,          // 云存储图片 fileID 数组
  filePaths: Array,           // 云存储 PDF fileID 数组
  
  // 时间戳
  createdAt: Number,          // 存入时间；旧数据回退使用 id
  updateTime: Number,         // 最后修改时间
  playlistIds: Array,         // 所属歌单 _id，可加入多个歌单
}
```

歌单保存在 `playlists` 集合，包含 `name`、`createdAt` 和 `updatedAt`；系统自动写入 `_id` 与 `_openid`。

## 💡 主要功能说明

### 三维度检索系统

**筛选维度**
- 乐器：全部/吉他/尤克里里
- 风格：全部/弹唱/指弹
- 曲谱类型：全部/图片谱/纸质归档/文字谱

**排序方式**
- 最新存入：按不可变的存入时间降序
- 最早存入：按不可变的存入时间升序
- 按名字：按 `title` 升序（A-Z 字母顺序）

**搜索逻辑**
- 排除 `status === 'deleted'` 的记录（不搜索回收站）
- 支持模糊匹配，同时检索歌名和歌手名
- 不区分大小写

### 删除与恢复

曲谱库中的删除操作会将曲谱移入回收站。回收站不会自动清理；用户可以恢复曲谱，或手动彻底删除曲谱及不再被其他曲谱引用的附件。

## 🔧 开发说明

### 添加新功能

1. 在 `pages/` 中创建新页面文件夹
2. 按照现有页面结构创建 `.js`、`.wxml`、`.wxss`、`.json` 文件
3. 在 `app.json` 的 `pages` 数组中注册新页面

### 修改数据结构

- 增删字段时，确保向后兼容
- 对于旧数据缺失的字段，在读取时设置默认值
- 云端数据字段变更需同时检查列表、搜索、编辑、阅读和回收站页面
- `utils/localStore.js` 仅用于后续迁移或紧急回退，不是当前主数据源

## 📝 使用建议

1. **定期备份**：请在「我 → 备份全部数据到电脑」中保存云数据库记录及云存储文件，并妥善保管离线副本
