# 歌单功能的云开发配置

本次改版新增 `playlists` 集合。代码已对 `songs` 和 `playlists` 的所有查询显式加入当前用户 `_openid` 条件；集合仍需在微信云开发环境中创建并设为仅创建者可读写。

## 上线前配置

1. 打开微信开发者工具的“云开发”，确认环境为 `cloud1-d3gcweweaf4589ab4`。
2. 在数据库中创建集合 `playlists`。
3. 将 `songs` 和 `playlists` 的数据权限设置为“仅创建者可读写”。若使用自定义安全规则，读写条件均应限制 `doc._openid == auth.openid`。
4. 不需要手动新增字段。首次创建歌单时会写入 `name`、`createdAt`、`updatedAt` 和系统生成的 `_openid`；曲谱首次加入歌单时会新增 `playlistIds` 数组。
5. 在模拟器中新建歌单并加入一首曲谱，然后退出并重新进入，确认歌单和数量仍存在。

## 验证失败时的表现

- 集合未创建：歌单页显示“歌单数据尚未配置”，不会伪装成空歌单。
- 权限不匹配：页面显示权限错误和重试入口。
- 批量加入或移除只有部分成功：成功项保留，失败项仍保持选中，可直接重试。

## 回收站

回收站不再承诺 30 天自动删除。彻底删除会先写入 `purgeStarted`，再清理没有被当前用户其他曲谱引用的附件，最后删除数据库记录。中途失败时记录保留在回收站，恢复入口会禁用，用户可重试彻底删除。

## 验收记录

- 本地数据层测试覆盖用户隔离、分页、歌单增删改、关联去重、回收站恢复和附件清理重试。
- 仓库代码无法自行创建线上集合或修改线上权限；完成上述控制台步骤前，歌单功能不算已在云端生效。
